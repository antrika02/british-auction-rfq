# British Auction RFQ System

An RFQ (Request for Quotation) system with British Auction bidding:
suppliers lower their prices, and the auction automatically extends
when bids arrive near the closing time, but never past a forced close time.

## Status
Work in progress.

## Planned stack
- Backend: Python + FastAPI
- Database: PostgreSQL
- Frontend: Next.js
- Live updates: WebSocket
